# Installation notes Ubuntu

## Clone repo and copy files to ~/.config/nvim

## Setup tree-sitter-cli
sudo apt install curl tar build-essential
sudo apt install cargo
sudo apt install rustup
rustup default stable
cargo install tree-sitter-cli

## Install npm
sudo apt install nodejs npm -y

## Other tools that might be missing
sudo apt install vim-gtk3
sudo apt install ripgrep
sudo apt install unzip

## For WSL
Install win32yank.exe in windows and put it in one of the locations in
PATH
